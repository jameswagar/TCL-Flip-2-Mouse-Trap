# Mouse Trap v1.0.1

This point release applies the same uniform wallpaper shading used by Power Saver across the full app window.

## Changes

- Apply an even 85% window-level wallpaper dim behind the title, status, app list, and save control.
- Make the list and cache backgrounds transparent so the shading remains uniform from top to bottom.
- Keep existing target selection, secure-setting storage, LSPosed integration, and D-pad behavior unchanged.

- Version name: `1.0.1`
- Version code: `6`
